Security Policy

Supported Versions

Saat ini versi terbaru IQIHLO ES TEH adalah versi yang didukung untuk perbaikan keamanan.

Reporting a Vulnerability

Jika menemukan masalah keamanan pada aplikasi IQIHLO ES TEH, jangan mempublikasikan detail kerentanan di Issues.

Laporkan kepada pemilik repository secara pribadi agar masalah dapat diperiksa dan diperbaiki.

Mohon sertakan:

- Penjelasan masalah
- Langkah untuk mereproduksi masalah
- Dampak terhadap aplikasi atau data
- Screenshot atau bukti pendukung jika tersedia

Important Security Notes

- Jangan menyimpan password owner atau password pengguna secara langsung di source code.
- Jangan memasukkan private key atau secret Firebase ke dalam repository.
- Gunakan Firebase Authentication dan Firebase Security Rules untuk membatasi akses database.
- Jangan membagikan token akses GitHub atau Firebase.
